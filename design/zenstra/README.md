# Zenstra enterprise design direction (phase 1)

Research, strategy and mockups for the Zenstra website and console. No
production code is changed by this folder.

| File | What it is |
|---|---|
| `index.html` | The design direction: product understanding, personas, competitive research, website audit, strategy, information architecture, design system, motion, responsive and accessibility rules, implementation plan, open decisions |
| `home.html` | Homepage mockup, with numbered design notes |
| `platform.html` | Platform (product overview) page mockup |
| `console.html` | Console mockup: security overview, detection queue, investigation, agent record, deployment health, command palette (Ctrl/Cmd K), emergency stop |
| `assets/zx.css` | Design tokens and core components (light and dark) |
| `assets/site.css` | Shared marketing-site layout, header and footer |

`index.html` is written as an artifact body without its own `<!doctype>`;
open the other pages directly in a browser. All data in the mockups is sample
data for a fictional credit union.
