Architecture

Where Zenstra sits, and what crosses the line.

Today most agents call tools directly with standing credentials. Zenstra adds one decision point in your environment. Only decisions and redacted evidence leave it.

Today

Agents call tools directly

  • {{icon:x}}Every call goes through, including the one a poisoned document asked for
  • {{icon:x}}Credentials stay valid for months, scoped to everything
  • {{icon:x}}Logs show the API call, not the decision behind it
With Zenstra

Every call meets a decision first

  • {{icon:check}}The malicious call stops at the decision point, in 14 ms
  • {{icon:check}}Grants are scoped to the task and expire per call or per session
  • {{icon:check}}Every decision is recorded with the policy and evidence behind it

SDK. Wraps the agent's tool layer, so it sees the plan, retrieved content and memory writes. Best for agents your teams build.

Gateway. A proxy in your VPC. Point MCP clients and agents at it: no code change. Sees every tool and API call on the wire.

Endpoint app. Deployed by MDM to managed devices. Covers Copilot, ChatGPT and other AI tools employees already use.

Securing Zenstra

A control in the path of every action has to be trustworthy itself.

The first question about any inline control is what happens when it is wrong, slow or compromised. These are the answers. The full detail is in our Trust Center.

{{icon:cloud}}

Your data stays with you

Prompts and tool payloads are evaluated inside your environment. The control plane receives decisions and redacted evidence only.

{{icon:shield}}

Fail-closed, with an exit

If a decision point is unreachable, actions are held. Low-risk tools can be set to fail-open, and those decisions are recorded on recovery.

{{icon:key}}

No single key opens everything

Per-tenant encryption keys, per-agent identities, and console access through your identity provider with role-based permissions.

{{icon:list}}

A ledger you can verify

Each entry is chained to the previous one, so the chain can be checked independently of Zenstra.

{{icon:target}}

Tested from outside

Annual independent penetration test and a public vulnerability disclosure policy.

{{icon:file}}

Software you can inspect

A software bill of materials ships with every SDK, gateway and endpoint release.
