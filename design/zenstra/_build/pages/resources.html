Glossary

Agentic AI security, defined.

Plain definitions for the terms in this site, our documentation and your next security review.

AI agent
Software that uses a model to plan and take actions, such as calling tools, on its own or on a person's behalf.
Agent identity
A verifiable identity for a specific agent, separate from the person or service account it acts for.
Agent-to-agent (A2A)
Agents delegating tasks to other agents. Each hop is a new caller that needs its own decision.
Decision point
The component that evaluates identity, content, policy and intent and returns allow, step-up or block.
Excessive agency
An agent holding more tools, data or permissions than its task needs.
Fail-closed
When the decision point is unavailable, actions are held rather than allowed.
Indirect prompt injection
Instructions hidden in content an agent reads, such as a document or web page, that try to change what it does.
Model Context Protocol (MCP)
An open protocol that exposes tools and data to agents. Each MCP server is an access grant.
Non-human identity
Any identity that is not a person: service accounts, API keys, workloads and agents.
Shadow AI
AI tools and agents operating without the security team's knowledge or approval.
Step-up
A verdict that holds an action until a named person approves it.
Tamper-evident ledger
A record where each entry includes the hash of the previous one, so any change is detectable.
