Runtime detection

Each agent measured against its own baseline.

Agents change hour by hour. Zenstra learns each agent's normal tools, data reach and call volume, and flags drift mid-task, before a gradual widening of scope becomes an incident.

  • Drift scores per agent, with the run that triggered them
  • New tools and new data classes flagged the first time they appear
  • Detections ranked by severity and blast radius
