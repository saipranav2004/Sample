What Cloud Security does.

Gateway for MCP and APIs

Deployed with Helm or Terraform in AWS, Azure or Google Cloud.

Scoped credentials

Per-agent identity and short-lived grants for Bedrock, Azure OpenAI and Vertex AI.

Context vault

Scoped secrets and retrieved context, never raw.

Fail-closed, fast

Decisions at 18 ms p95. If Zenstra is unreachable, actions are held.

How it works

Live in four steps.

  1. 01Deploy

    Install the gateway in your VPC or cluster with Helm or Terraform.

  2. 02Register

    Agents, MCP servers and models get an identity and scoped, expiring grants.

  3. 03Enforce

    Guardrails as code, evaluated on every call.

  4. 04Record

    A tamper-evident trail with live risk scoring.

FAQ

Questions teams ask first.

ISO 27001 · SOC 2 Type II · ISO/IEC 42001 · ISO/IEC 27701 · Compliance

Does our data leave our cloud?

No. The gateway runs in your VPC or Kubernetes cluster, and payloads never leave your environment.

What if the gateway is unavailable?

It fails closed: actions are held, never waved through.

Which clouds and models are supported?

AWS, Azure and Google Cloud, including Amazon Bedrock, Azure OpenAI and Vertex AI.
